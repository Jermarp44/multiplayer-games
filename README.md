# Gameverse Arena

A polished browser-based arcade showcase featuring 8 multiplayer-inspired game concepts built with HTML, CSS, and vanilla JavaScript.

## Overview

This project presents original concepts inspired by the games you described:

- ChopChop.io — lumberjack battle in a shrinking forest
- Blob Magnet — magnetic arena chaos with attract/repel physics
- Neon Line Racer — neon trail survival arena
- SyncDefenders — rhythm-based co-op tower defense
- Escape the Code — cooperative puzzle and code-based escape
- Pixel Art Heist — social deduction with rotating camera feeds
- GridCommand — fast 10-second tactical grid combat
- DeckBuilder Arena — shared-pool card battlefield

## Live Demo

Open `index.html` directly in a browser, or run a local web server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## How It Works

- Select a game from the left-side gallery
- The main stage updates to that concept
- Some prototypes include simple keyboard controls
- Each game is a lightweight prototype and visual demo rather than a full production game

## Controls

- ChopChop.io: `W`, `A`, `S`, `D` to move, `Space` to chop trees
- Blob Magnet: arrow keys to move, `E` / `Q` to switch polarity
- Neon Line Racer: arrow keys to steer
- Other concepts are visual demos and use simple loop animations with no advanced control scheme

## Notes

This is meant to be a creative showcase of playable concept prototypes, not a complete networked multiplayer backend. The idea is to demonstrate the visual style and core mechanics of each game in a single HTML project.
